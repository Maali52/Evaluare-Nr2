🔀 I. Branch - Operațiuni

1 Creare branch stage

git checkout -b stage
git push origin stage

2 Creare hosts.xml în branch stage

git add hosts.xml
git commit -m "Commit file hosts.xml"
git push origin stage

3 Merge stage în master

git checkout master
git merge stage
git push origin master

🔀 II. Branch - Operațiuni avansate

1 Creare branch dev din stage

git checkout stage
git checkout -b dev

2 Creare env.txt și commit

git add env.txt
git commit -m "Commit file env.txt"

3 Merge dev în stage

git checkout stage
git merge dev
git push origin stage

🔀 III. Branch - Redenumire

1 Redenumire dev în develop

git branch -m dev develop

git push origin --delete dev
